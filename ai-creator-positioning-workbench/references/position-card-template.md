# 《AI 账号定位卡》固定模板（步骤 9 输出格式）

> 字段来源：课稿第二节「定位表五题」+「30 秒自检」逐字对应；三版候选记录、优势/风险/变现路径、8—10 选题方向为反馈文档定稿规格；⚪ 排版样式为推导。

```
# AI 账号定位卡 ｜ {账号名/学员名} ｜ {日期}

## 定稿定位（由学员本人选定/组合/修改，AI 未代定案）
1. 账号类型：{四类之一；AIGC 创作者注明：作品展示型 / 教学陪跑型}（承接第一课成果）
2. 身份标签（我是谁）：{标签}
   - 标签类别：{职业 / 经验 / 技能 / 阶段性身份}
   - 真实证据：{学员亲口提供的作品/项目/数据/服务记录，逐条列出}
3. 服务对象：{对象描述}
   - 四条件检查：能理解 {✓/✗ 依据}｜能持续观察 {✓/✗ 依据}｜有真实 AI 任务 {✓/✗ 依据}｜有商业承接可能 {✓/✗ 依据}
4. 具体问题区：{一片能持续生长内容的问题区，落到高频任务}
   - 宽度验证：{本版 8—10 个选题方向清单}
5. 一句话定位：我是【{身份标签}】，我面向【{服务对象}】，帮助他们解决【{具体问题}】。

## 变现路径
- 主路径：{路径}（依据：第一课交叉连线表 + 学员第一课初步路线）
- 涉及金额测算时逐条标注：（课程公式推演，非收入承诺）

## 定位四问自检（30 秒自检）结果
1. 身份标签能不能支撑我讲这个内容？——{答}
2. 这个服务对象我能不能持续观察？——{答}
3. 这个具体问题能不能长出至少 10 条内容？——{答}
4. 这个方向未来有没有可能承接收入？——{答}
（两个以上答不上来 → 本卡不定稿，回流程第 3—5 步调整）

## 备选定位（未采用，供下一课对标验证时回看）
- 候选 B：{一句话定位}｜优势：{…}｜风险：{…}｜适合变现路径：{…}｜宽度验证结论：{…}
- 候选 C：{同上}

> 课程提醒：「定位是一个等待验证的假设」——下节课借助对标账号验证赛道与定位的可行性。
```
