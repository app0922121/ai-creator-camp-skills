# 发布前自检规则集（种草规则集，成稿后强制执行）

来源：反馈定稿规格要求「S-16 与体检器·种草规则集合并为一个 skill」；判据全部取自课程第八节原文（继承 sm-publish-gate 种草规则集，其判据均标注源自课稿）。

## 一、四锚点逐环体检表

对成稿的四个位置逐一体检，每环按判据给结论：

| 位置 | 用户的真实问题 | 锚点 | 合格判据（课稿原文措辞） |
|---|---|---|---|
| 开头 | 你为什么推荐它（恰饭了吗） | 立场锚 | "关系说清楚，利益不藏着"——商单/分销/自有产品三种关系任一种，必须明示 |
| 引入 | 你真的用过吗 | 在场锚 | 时间痕迹（"从2.0用到3.0"）、失败经历（"上传白底图会过曝"——编不出的具体翻车）、使用成本（"烧了两百多块灵感值"）三者至少其一 |
| 介绍 | 效果稳定吗 | 边界锚 | 说清"做哪件事、做到什么程度、解决什么问题"；主动说什么时候不可靠；缺点必须"真实、具体、但不影响真实用户选择"（"唯一缺点是太好用了"= 假缺点，不合格） |
| 行动 | 我是小白我做得到吗 | 验证锚 | 降级演示 / 复现路径（"你照这三步也能做到"）/ 可当场验证的低成本动作，至少其一 |

判定逻辑：
- 某环**缺锚** → 🟡 缺项，回到该环补写；
- 有锚但属**零伪造成本表述**（见下）→ 🟡，就地替换；
- **声称在场/使用但用户未确认真实使用** → 🔴 拦截——直接问用户"这条你真的用过/测过吗？"，答案决定拦截还是放行，不替用户回答；
- 缺点是假缺点 → 🟡，顶回重写。

## 二、零伪造成本空话标注

逐句扫全文，标出所有"谁都能写"的句子：

- 识别对象（课稿原文）："形容词、感叹号、空头承诺，这些东西谁都能写"——如"效果非常炸裂""谁用谁知道""绝了""必备神器"；
- 每处给一个高伪造成本的替换方向（课稿原文）："过程、数据、翻车经历、使用边界，这些东西编不出来"；
- 替换不了的删。

## 三、自检结论（三档）

- 🔴 **拦截**：在场细节未经用户确认真实，或立场锚缺失（利益关系未披露）。不输出可发布版本，先解决。
- 🟡 **整改后可交人审**：缺锚 / 零伪造空话 / 假缺点，逐条给出改法并改完复检。
- ✅ **可交人审**：四环有锚、无空话残留、事实句全部来自用户提供。

任何结论都不等于"可直接发布"：**全文人审后才发**（反馈定稿规格铁律）。
