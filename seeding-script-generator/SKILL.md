# seeding-script-generator · 信任种草脚本生成器

课稿第八节的装配实现："只需要提供你想推荐的产品和你的真实使用素材，它就会带着你，按照四个锚点，生成一版属于你自己的信任种草脚本。"底层机制是**伪造成本**："一条信息的可信度，不取决于它说了什么，而取决于它有多难被伪造。"锚点定义、话术范例与 HeyGen 实战改写全文见 `references/anchor-course.md`；成稿后的自检规则见 `references/self-check-rules.md`。

## 铁律（源自课程红线与反馈定稿规格，违反即输出无效）

1. **在场细节必须真实**——真实使用素材是强制输入。用户拿不出使用痕迹（时间痕迹/翻车经历/使用成本任一）→ 不生成，改为输出"先去真用"的体验清单（用多久、记什么）。虚假种草是平台重点处置对象（小红书半年处置虚假种草 320 万篇）。
2. **立场先行**——"关系说清楚，利益不藏着"。商单/分销/自有产品三种关系必须先问清，开头必须有立场锚；商单不能收了钱装自来水。
3. **事实句只来自用户素材**——翻车细节、时间痕迹、花费数字一律取自用户提供；AI 补写的示范句逐句标 ⚪ 待核实，绝不替用户编"真实点的细节"。
4. **全文人审后才发**——自检通过 ≠ 可发布，最终发布前必须由用户逐句人工审核。

## 第 1 步 · 收集输入（一次问齐）

①产品与推荐场景 ②**利益关系**：商单收费 / 挂链接分销 / 自有产品 / 纯自来水 ③**真实使用素材**：用了多久（版本变迁）、具体翻车经历、花了什么成本（钱/时间/踩坑）④产品的真实短板（什么时候不可靠）⑤目标用户与其最担心的事 ⑥读者能低成本验证的动作（免费额度/试用入口/免费第一课）。

③④给不出 → 触发铁律 1，停。

## 第 2 步 · 四锚点逐位成稿

按种草公式四个位置放锚，每段 1-3 句（判据与原文话术范例见 `references/anchor-course.md`，改写手感对照其中 HeyGen 四段示范）：

| 位置 | 回答用户的疑问 | 用输入的哪项 | 要点 |
|---|---|---|---|
| 开头·立场锚 | 你为什么跟我说这个 | ②利益关系，选商单/分销/自有对应话术 | "先钩子，后说明你的立场"——首要任务是留住人 |
| 引入·在场锚 | 你真的用过吗 | ③素材（时间痕迹/翻车/成本） | "结果可以抄，过程抄不了"，翻车是最强在场证明 |
| 介绍·边界锚 | 效果稳定吗、有没有我不知道的坑 | ④短板 | 说清"做哪件事、做到什么程度、解决什么问题"，再主动说什么时候不可靠 |
| 行动·验证锚 | 我是小白我做得到吗 | ⑥验证动作 | 降级演示（小白级输入）/复现路径/可当场验证，"你敢让用户验证，本身就是最强的信任信号" |

商单场景保持可信的写法：照立场锚商单话术示范——说清合作关系＋你的接单条件（"实测不过关的部分，必须允许我说出来"），缺点照写不删。

## 第 3 步 · 发布前自检（内置，不可跳过）

成稿后立即按 `references/self-check-rules.md` 执行两项体检：

1. **四锚点逐环体检**：四个位置逐一对判据——缺锚 🟡 回补；声称在场但未经用户确认真实 🔴 拦截（直接问用户"这条你真的用过/测过吗？"）；假缺点顶回重写。
2. **零伪造成本空话标注**：逐句标出形容词堆砌、感叹号、空头承诺（谁都能写的句子），每处给替换方向（过程/数据/翻车/边界），替换不了的删。

结论三档：🔴 拦截 / 🟡 整改后复检 / ✅ 可交人审。

## 输出（固定模板）

```
# 信任种草脚本 ｜ {产品} ｜ {利益关系} ｜ {日期}
## 脚本正文（四锚点位置已标注）
【开头·立场锚】…【引入·在场锚】…【介绍·边界锚】…【行动·验证锚】…
## 自检报告
结论：🔴/🟡/✅ ｜ 四环体检结果 ｜ 零伪造空话标注与替换（逐条）
## ⚪ 待人工核实句
| # | 句子 | 需确认的事实 |
## 下一步
1. ⚪ 清单逐条核实 → 2. 🟡 项改完复检 → 3. 全文人审通过后再发布
```

## 边界

- 假缺点（"唯一缺点是太好用了"）不算边界锚，会被顶回重写。
- 用户要求"写得夸一点/别提缺点/别说是广告" → 提醒这同时踩伪造成本机制与平台治理红线，坚持出带立场锚与边界锚的版本；夸张版不出。
- 本 skill 管种草脚本；售卖转化（算账+三闸）走 purchase-decision-copywriter，商单接单报价走 zhijia-deal-pricing。发不发、发哪个平台由用户定。
