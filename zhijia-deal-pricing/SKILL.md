# zhijia-deal-pricing · 智价·商单报价测算器

把「拍脑袋报价」变成算得清的账：**Brief 确认表（十项防漏）→ 底价公式测算 → 三条价格线 → 六格拆分 → 三档方案**，可选谈判陪练。课稿第十二节原理："需求没问清，价格就没有计算基础。"全部公式、指令与示范原文见 `references/pricing-course.md`。

## 铁律（源自课程红线，违反即输出无效）

1. **最终报价必须人拍板**——课稿原文："最后由你来确定价格。"AI 只出测算与草案，测算结果是决策依据，不是定价。
2. **不得编造市场价格**——课稿指令原文："所有无法确定的数据必须向我追问，不得自行编造市场价格。"给不出真实数据的项标「待补」，不填估值充数。
3. **Brief 整理不替品牌补条件**——课稿指令原文："不得替我补充品牌没有明确说明的条件。"品牌没说的进「仍需追问」，不脑补。
4. **涉密先脱敏**——课稿原文："如果需求涉及未发布产品、合同、用户信息或品牌内部数据，必须先脱敏。"收到未脱敏材料先提醒。
5. **谈价减范围，不做无理由打折**——课稿原则原文："预算减少，交付范围同步减少。"

## 第 1 步 · 确认要做哪件 + 收集输入

三个模块可单用可串联，先问本次做哪个：**①Brief 确认 ②报价测算 ③谈判陪练**。按所选一次问齐：
- ①需要：品牌给的原始需求材料（微信/邮件/文档摘录，先脱敏）。
- ②需要（逐项问真实值）：预计工作时长、个人时薪怎么算、直接成本（道具/交通/场地）、机会成本、风险预留、税费与平台成本；再问是否涉及授权/排他/投流/加急。
- ③需要：已有的报价方案（没有先走②）＋想练的情景。

## 模块① Brief → 商单确认表（十项防漏）

照课稿 AI 指令执行（原文见 references §2）：把需求整理为四栏——**已确认的信息 / 仍需追问的信息 / 可能增加成本的要求 / 可能存在风险的要求**。

重点检查十项：交付形式、发布平台、时间、修改次数、重拍条件、原始素材、**使用权限（授权）**、投流、**竞品排他**、付款和开票。每项标 ✅已明确 / ❓需追问 / 💰增成本 / ⚠️有风险。「仍需追问」栏配合课稿「需求十问」（references §1）生成追问话术——"报价前多问一个问题，交付时就少踩一个坑。"授权项必须问到五件事：谁使用、在哪用、怎么用、用多久、能否修改；排他项必须问到品类和时间怎么界定（十问第9问）。涉及合同条款时读 references §7（合同十件事＋六个坑＋承诺红线）。

## 模块② 报价测算（价格带 + 六格 + 三档）

1. **底价线**：`底价＝工作时长×个人时薪＋直接成本＋机会成本＋风险预留＋税费及平台成本`。算完必附课稿提醒：这只是"成本底线，不是市场价，更不是建议你直接对外报"这个数。
2. **标准价**：底价＋账号发布价值＋合理利润，作为日常合作价。账号发布价值没依据时，按课稿办法引导用户自查"同粉丝量级或者账号数据持平账号的报价范围"——这个数由用户查证提供，AI 不代填。
3. **价值价**：项目含"投流、长期授权、复杂拍摄、竞品排他、加急或多平台使用"时进入。
4. **六格拆分**：内容制作费 / 账号发布费 / 授权使用费 / 竞品排他费 / 增值服务费 / 税费及平台成本，逐格给构成明细（各格定义原文见 references §3）。排他要单独收费——"品牌要求你一段时间不接同类产品，就是在占用你未来的接单机会"。
5. **三档方案**：体验 / 标准 / 整合（范围定义照原文 references §5），必附课稿提醒：三档"不是为了造高价锚点，而是让品牌明白：预算变化，对应的是合作范围变化"。

## 模块③ 谈判陪练（可选）

课稿依据："AI 可以……还能扮演品牌采购跟你演练谈判。"AI 扮演品牌采购，围绕用户的三档方案演练（如压价、预算不变加投流加排他）。每轮之后按课稿谈价原则复盘：是否守住"减范围不减价"；可调整的七个变量（内容数量、制作复杂度、修改次数、授权期限、使用平台、排他范围、交付速度）用了哪个。课稿示范应答与练习答案见 references §6。

## 边界

- AI 做理需求、算账、拆分、陪练；**接不接、报多少、让不让步，全部归用户**。
- 用户给不出工时/成本等真实数据 → 对应项标「待补」，输出降级为部分测算，不用编的数字凑完整。
- 谈判陪练是演练不是话术保证；对外承诺只承诺可控过程（references §7 承诺红线），播放量/销量类结果不进报价承诺。
- 合同审查、找品牌写邀约不在本 skill 范围（课稿分别属交付与主动 BD 环节）。
